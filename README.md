### 🚀 Highlights
- 🖥️ **3D Interactive Retro PC** — Interactive Three.js desktop canvas with dynamic orbital controls.
- 🌍 **Floating Earth & Stars** — Real-time rotating planet canvas with procedural twinkling starfields.
- 🎴 **Parallax Tilt Cards** — Smooth 3D glare cards for projects & skills powered by Framer Motion.
- ⚡ **Optimized Performance** — Lazy-mounted canvases, WebP assets, and 60fps responsive layout.
